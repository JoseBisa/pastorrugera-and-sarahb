# Sarah & Ruge Wedding

# Build a Premium Luxury Wedding Website/Web App



Create a world-class wedding website/web application that feels comparable to luxury wedding brands and high-end event websites. The experience should be cinematic, emotional, elegant, romantic, and premium.



## Project Overview



Build a responsive wedding website for:



**Sarah & Ruge**



The website must tell the couple's story, provide wedding information, allow guests to RSVP, leave messages, register gifts, and access all event details.



The website should be optimized primarily for mobile devices since most guests will access it through QR code invitations using their smartphones.
